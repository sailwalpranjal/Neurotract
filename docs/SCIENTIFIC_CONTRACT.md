# NeuroTract 2.0 — Scientific Contract

This document governs the scientific integrity, mathematical formulations, assumptions, and terminology across all NeuroTract 2.0 components.

---

## 1. Non-Negotiable Scientific Principles

1. **No Axon Equivalence**: Reconstructed streamlines are mathematical integral curves following local water diffusion principal directions or FOD peaks. They are **not** literal physical axons. UI labels must explicitly use "reconstructed streamline" or "algorithmic pathway".
2. **No Clinical Diagnosis**: NeuroTract is research analysis software. It does not provide diagnostic classification, clinical evaluation, or automated medical judgements.
3. **No Arbitrary Health Scores**: Network metrics reflect mathematical graph properties of the parcellated matrix. They must never be aggregated into an unvalidated "brain health score" percentage.
4. **No Hidden Universal Norms**: Graph metrics depend on matrix size, parcellation scheme, edge thresholding, and weighting strategy. Universal "normal ranges" are invalid unless explicitly standardized to a specific normative atlas and cohort.

## 2. Mathematical Definitions & Formulations

### Diffusion Tensor Imaging (DTI)
The diffusion tensor $D$ is a $3 \times 3$ symmetric positive-definite matrix:
$$S(g, b) = S_0 \exp(-b g^T D g)$$

Eigenvalue decomposition yields $\lambda_1 \ge \lambda_2 \ge \lambda_3 \ge 0$ with orthonormal eigenvectors $v_1, v_2, v_3$.

- **Mean Diffusivity (MD)**:
  $$\text{MD} = \bar{\lambda} = \frac{\lambda_1 + \lambda_2 + \lambda_3}{3} \quad [\text{mm}^2/\text{s}]$$
- **Fractional Anisotropy (FA)** (Basser & Pierpaoli, 1996):
  $$\text{FA} = \sqrt{\frac{3}{2}} \frac{\sqrt{(\lambda_1 - \bar{\lambda})^2 + (\lambda_2 - \bar{\lambda})^2 + (\lambda_3 - \bar{\lambda})^2}}{\sqrt{\lambda_1^2 + \lambda_2^2 + \lambda_3^2}}$$
  Equivalently:
  $$\text{FA} = \sqrt{\frac{1}{2}} \frac{\sqrt{(\lambda_1 - \lambda_2)^2 + (\lambda_2 - \lambda_3)^2 + (\lambda_3 - \lambda_1)^2}}{\sqrt{\lambda_1^2 + \lambda_2^2 + \lambda_3^2}}$$
- **Radial Diffusivity (RD)**:
  $$\text{RD} = \frac{\lambda_2 + \lambda_3}{2} \quad [\text{mm}^2/\text{s}]$$
- **Axial Diffusivity (AD)**:
  $$\text{AD} = \lambda_1 \quad [\text{mm}^2/\text{s}]$$

### Constrained Spherical Deconvolution (CSD)
Models the diffusion signal $S(\theta, \phi)$ as the spherical convolution of a single-fiber response function $R(\theta)$ with the Fiber Orientation Distribution $F(\theta, \phi)$:
$$S(\theta, \phi) = R(\theta) * F(\theta, \phi)$$
Decomposed in a real symmetric spherical harmonic basis up to order $L_{max} = 8$:
$$N_{\text{coeffs}} = \frac{(L_{max} + 1)(L_{max} + 2)}{2} = 45$$
Constrained by non-negativity: $F(\theta, \phi) \ge 0$.

### Graph Theoretical Metrics
For an adjacency matrix $A$ with $N$ parcels:
- **Density**:
  $$\rho = \frac{2 E}{N(N-1)}$$
- **Clustering Coefficient**:
  $$C_i = \frac{2 t_i}{k_i (k_i - 1)}, \quad C = \frac{1}{N} \sum_{i=1}^N C_i$$
- **Global Efficiency**:
  $$E_{\text{glob}} = \frac{1}{N(N-1)} \sum_{i \neq j} \frac{1}{d_{ij}}$$
  where $d_{ij}$ is the shortest path length between nodes $i$ and $j$.
- **Modularity**:
  $$Q = \frac{1}{2m} \sum_{ij} \left( A_{ij} - \frac{k_i k_j}{2m} \right) \delta(c_i, c_j)$$
